# 从文档 / 说课稿 / 课本新做（在《通用.md》基础上追加）

- 【关键】依据材料：说课稿 / 教案 / 课本页 / Word 文档；以哪份为准
- 【关键】页数与结构：按稿子逐段一页，还是要压缩（经验：18 页被要求压到 12 页）
- 【关键】讲稿是否放进备注
- 说课/比赛的环节结构（教材分析、学情、目标、重难点、教法学法、过程、板书、反思…）是否按固定模板
- 主题要求（如"数智化""AI 赋能"）要怎么体现：固定面板 / 每环节标注
- 页面上放多少字：只放关键词 / 完整句子
- 示意数据、示意截图是否可以（必须标"示意"）
- 例题、公式、图形：可编辑公式还是图片
- 学科、年级相关的配色与图形风格
