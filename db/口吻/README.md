# 口吻库怎么建

AI 靠这里的两份文件模仿主理人说话：
- `画像.md`：提炼出的习惯规则（AI 维护，主理人可随时改）
- `范例.md`：主理人真实发过的消息，按场景分类（越多越像）

## 冷启动：请主理人提供聊天样本
1. 从企业微信挑 30～50 张聊天截图（或导出文字），覆盖这些场景：
   开场接单、问需求、解释做法、发样张、交付、客户提意见、客户不满意、催进度、收尾道谢。
2. 放进 `db/口吻/原始/`（这个文件夹不进版本库）。
3. 对 AI 说"学习口吻"，AI 会只提取**主理人自己发的话**，去掉客户隐私，写入画像和范例。

## 日常积累
每次主理人修改了 AI 的草稿再发出，把实际发出的版本贴回来，AI 会自动收进范例库（见 `skills/retro`）。
