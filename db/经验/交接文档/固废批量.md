## 风格标准（必须严格遵守）
1. **比例**：16:9（13.333″ × 7.5″）。内容必须铺满整个宽度（左右边距约 0.6″），**不能是把 4:3 内容堆在中间**——这是客户明确否决过的问题。
2. **封面（主页）**：浅蓝背景上一条全宽蓝色横带 `#1A5F9A`，白色大标题"固体废物处置与资源化"，下方浅色副标题为章名，左下一个橙色小竖条 `#EE8742`。
3. **节标题页**（第一节/第二节…）：同封面样式的蓝色横带，上方小字"第X节"，下方节名。
4. **内容页标题**：左上实心蓝色矩形 `#1A5F9A`（约 0.6″,0.42″ 起，宽 6.3″，高 0.74″），白色粗体 24pt 左对齐；标题框左下方一个橙色小竖条。标题过长时可加宽或缩小字号，但不能溢出。
5. **背景**：全部页面浅蓝 `#E8F0F9`；正文文字放在**白色卡片**上；卡片不能遮挡图片。
6. **字体**：全部微软雅黑（包括图表）。字号分档：28 / 24 / 20 / 18 / 16（极少数图注、公式说明可到 12–14）。
7. **颜色**：正文深灰 `#333333`；小标题蓝 `#1A5F9A` 粗体；重点词红 `#C0392B` 粗体；其他杂色全部收敛到这三色。
8. **页脚**：左下灰色小字"固体废物处置与资源化 · 第X章 …"，右下页码。
9. **不要**：校徽、学校名称、动画、切换效果、阴影、3D、渐变、装饰性小圆球/小图标。
10. **客户排版要求（原文）**：
    - PPT 按 16:9 制作，校对好内容及排版（标题缩进、加粗等）；最终定稿转 PDF。
    - PPT 中**不要插入视频、动画、动图**等。

## 已有工具链（Python，需 Windows + PowerPoint，依赖 python-pptx、lxml、pywin32、Pillow）
在 `_工具脚本` 目录下运行，章节配置在 `decks/chN.py`（章名、目录页、节标题页位置）：
```
python engine.py <原稿.pptx> <中间.pptx> assets decks/ch3.py   # 主题/母版/封面/目录/节页/自动16:9排版/字号/字体
python fit.py <中间.pptx> <输出.pptx>                            # 用 PowerPoint COM 实测文字高度，修正重叠、溢出、竖排、图文遮挡、卡片
python strip_media.py <输出.pptx>                                # 删除链接、视频、音频、悬停音效、动画，动图转静态
python topdf.py <输出.pptx>                                      # 导出 PDF
python render.py <输出.pptx> <图片目录> 800                      # 逐页导出 PNG 用于检查
python grid.py <图片目录> <前缀> 4                               # 拼缩略图
python check.py <输出.pptx>                                      # 自动检查重叠/出界
python dbg.py <pptx> <页码...>                                   # 打印某页每个形状的位置和字号
```
注意：`engine.py` 内部 exec 了 `lib.py`、`lib169.py`、`fontfix.py`，需同目录。
