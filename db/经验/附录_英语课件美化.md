# 课件 PPT 美化：工具、流程与经验（给 Codex 学习）

来源：一次真实任务——把一份 27 页小学英语课件（Unit 4 Going shopping, Part C Reading time，132 MB，含动画、视频、音频）按客户要求美化，前后改了 7 轮。本文记录**实际用过、验证过**的做法和踩过的坑；`scripts/` 是当时用的脚本，`assets/` 是生成的素材。

---

## 1. 任务与客户要求（先读懂需求再动手）

客户原始要求：
1. 不改变内容，只改外表、形式。
2. 版式统一、好看；字体用 Comic（Comic Sans MS），字号都要 ≥ 24。
3. 课本原图不动、不改。
4. 整体美观大气、统一。

后续轮次追加的典型要求（很有代表性）：
- 所有“问题”和“答语”（如 *What is the story about? / Maybe it's about...*）字体、字号、颜色必须一致。
- Tips 要放回**原来的位置**（多在右上角），只改形式，不要加框。
- 任何“后出现的元素”必须**完全盖住**先出现的内容（遮罩/对话框边缘不能露出课本图原气泡）。
- 不能有内容压到/超出边框。
- 交互：思维导图“点哪个揭晓哪个”（触发器），弹窗“点击再出现”而不是自动。
- 中文注释、翻译类辅助文字可以小于 24（用户确认“合理的中文小无所谓”）。

**理解需求的经验**
- 客户常用截图 + 红圈 + 语音转文字表达，红圈圈住的就是“这一类”对象（例：圈了两处问答 → 规则适用于全册所有问答）。
- 需求之间冲突时（如“中文再小”vs“字号 ≥ 24”）照用户最新指令做，但**明确告知冲突**并给替代方案。
- 有歧义时说出你的理解再做（例：“第 26 页右侧规则”其实在第 25 页；“最后那句话点击弹出”指圈出的那一句）。
- “课本原图不动”：课本插图保持原图、原大小、原裁剪；只有在用户明确要求（如照片墙）或为避免出框做几 pt 微调时才移动，并在交付说明里写清楚。

## 2. 工具链（Windows）

| 用途 | 工具 | 说明 |
|---|---|---|
| 修改 PPT（主力） | **PowerPoint COM 自动化**：Python `pywin32`（`win32com.client.gencache.EnsureDispatch("PowerPoint.Application")`） | 直接在原文件上改，**形状 ID 不变 → 动画、触发器、音视频全部保留**。不要用“重新生成整份 PPT”的方式。 |
| 读取/核对 | `python-pptx`、`lxml`、`zipfile` + 正则 | 读文字、几何、XML 级动画结构 |
| XML 后处理 | `lxml`（不要用 ElementTree，会改坏命名空间前缀） | 统一字体槽位、字号下限、主题中文字体 |
| 渲染检查 | `Slide.Export(path, "PNG", w, h)`（PowerShell COM） + PIL 拼图 | 在 Windows 上比 LibreOffice 准确（真字体） |
| 素材 | PIL 画背景、图标（灯泡、雨伞、星/勾/叉、光芒） | 用画的 PNG 图标代替 emoji（emoji 在部分设备显示不出） |
| 文字测宽 | PIL `ImageFont.getlength`（comic.ttf / comicbd.ttf） + PowerPoint 自身 `AutoSize` 测量 | 规划布局用 PIL，最终摆放用 PowerPoint 实测 |
| Skill | Anthropic `pptx` skill（读文本 `slide_text.py`、`validate.py` 思路、设计与 QA 清单） | 其 LibreOffice/soffice 包装在 Windows 上不可用；改用 PowerPoint 导出 |

> Office 类型库要先生成：`gencache.EnsureModule('{2DF8D04C-5BFA-101B-BDE5-00AA0044DE52}', 0, 2, 8)`，否则 `TextFrame2.TextRange` 的很多调用会失败。

## 3. 工作流程（每一轮都照这个走）

1. **复制原件**到工作目录，原件永远只读；每轮都从原件重新构建（脚本可重复执行，结果可复现）。
2. **盘点**：每页每个形状的 id/名称/类型/位置/字号/字体，以及动画序列（类型、触发、延迟、目标形状 id）。
3. **渲染原稿**为 PNG 拼图，逐页看清版式问题。
4. **定设计系统**（见第 4 节），再逐页写布局代码（按 shape id 定位，不按名字——名字会重复/被本地化）。
5. **构建** → **XML 后处理** → **自动 QA** → **渲染拼图人工逐页看** → 修 → 重来。
6. **核对三件事**再交付：
   - 文字：与原稿逐页做“非空白字符计数”比对，只允许有意的增删。
   - 动画：**XML 级**比对原稿与成品的每个效果（类别/触发节点/目标 id），只允许有意的改动。
   - 版面：最小字号、文字溢出、元素越界（安全区）、字体槽位。
7. 交付时附总览图，并说明：改了什么、哪些是理解/假设、哪些没验证（如“放映没实际点击测试”）。

## 4. 这次的设计系统（统一感的来源）

- **底版**：主母版背景设为一张 PNG（浅绿渐变外圈 + 白色圆角面板 + 柔和阴影 + 细绿边），所有版式 `FollowMasterBackground`，删除版式里旧的装饰图形和每页的满屏底色矩形。
- **色板**：主绿 `3E7C4F`（标签/横幅）、深绿 `2E5E3B`（问题与答语）、浅绿边 `B9D8AE`、卡片浅绿底 `F1F8EE`；强调橙 `E9862A`；Tips 中文 `8A7356`；正文深灰 `333333`/`444444`。
- **页面标签**：左上角六边形购物车图标 + 绿色圆角药丸标签（白色 Comic 加粗 26 号），每页同一位置 (x=80, y=20, h=40)，宽度按文字实测。
- **问题与答语**：全册统一 Comic Sans MS 加粗、深绿；同一页问题与答语**同字号**（开阔页 28，卡片/标题行/气泡内 24）；只保留有教学意义的高亮（is/are 红、It's/They're 同一红色呼应，rainy day 橙，NEED 红）。
- **Tips**：无框；橙色灯泡图标 + 橙色加粗 “Tips:” 标签 + 深灰正文，序号橙色加粗，中文柔和棕灰；放在原稿 Tips 的位置。
- **总结口号**：绿色圆角横幅 + 白字（关键词亮黄）。
- **安全区**：内容距面板边 ≥ 约 6–10 pt；任何东西不压边框。
- **中文**：Comic 没有中文字形，中文用微软雅黑；英文-only 的文字框把东亚槽位也设为 Comic（否则弯引号 “ ” 会用中文全角字体，间距很怪）。

## 5. 关键技术做法（附代码要点，完整见 `scripts/example_build_unit4.py`）

### 5.1 按 id 找形状（含组内）
```python
def S(sl, sid):
    for s in sl.Shapes:
        if s.Id == sid: return s
        if s.Type == 6:                      # group
            for g in s.GroupItems:
                if g.Id == sid: return g
```

### 5.2 字体与字号（两套文本接口要分清）
- 逐 run 处理用**旧接口** `shape.TextFrame.TextRange.Runs(k, 1)`（`Font.Name / NameFarEast / Size / Color.RGB`）。新接口 `TextFrame2.TextRange.Runs(...)` 在 makepy 下是带参属性，调用会报错。
- 整体格式（自动调整、边距、换行、行距、字间距、发光）用 `TextFrame2`：`AutoSize / WordWrap / MarginLeft… / VerticalAnchor / ParagraphFormat.SpaceWithin / Font.Spacing / Font.Glow`。
- COM 改字体对某些槽位不生效 → 构建后用 `post.py` 在 XML 里统一：`a:latin`→Comic，`a:ea`→（含中文用微软雅黑，否则 Comic），`sz<2400` 提到 2400（可按段落文字豁免），主题 `<a:font script="Hans">` 改成微软雅黑。
- 原稿很多文字带“字间距加宽”，换 Comic 后会溢出 → `Font.Spacing = 0`。

### 5.3 用 PowerPoint 自己测宽来摆版
```python
def fit(s):                 # 单行文字框收缩到文字宽度，返回 (w, h)
    tf = s.TextFrame2; tf.WordWrap = 0; tf.AutoSize = 1
    w, h = s.Width, s.Height; tf.AutoSize = 0
    return w, h
```
注意：`TextRange.BoundWidth` 比实际文字宽约 10–12 pt，QA 判断溢出要扣掉这个偏差。

### 5.4 形状与样式
- 文字框可以直接改成圆角药丸：`shape.AutoShapeType = 5`；圆角比例 `shape.Adjustments.SetItem(1, 0.5)`。自定义几何的形状改不了（会报“值超出范围”）。
- 图片保持比例缩放：`LockAspectRatio = -1` 后只设宽。
- 旋转组合（如明信片 −2°）里放元素：先 `Ungroup`（无动画时安全），再用旋转公式摆放：
```python
def place(sh, dx, dy, ang):   # (dx,dy) 是相对卡片中心的局部坐标
    a = math.radians(ang)
    px = CX + dx*math.cos(a) - dy*math.sin(a); py = CY + dx*math.sin(a) + dy*math.cos(a)
    sh.Rotation = 0; sh.Left = px - sh.Width/2; sh.Top = py - sh.Height/2; sh.Rotation = ang % 360
```
- 曲线：`Shapes.BuildFreeform(msoEditingCorner, x0, y0)` + `AddNodes(msoSegmentCurve, msoEditingCorner, c1x, c1y, c2x, c2y, x, y)` + `ConvertToShape()`（思维导图分支、照片墙麻绳）。
- 复制形状：`shape.Duplicate().Item(1)`；跨页复制用 `Copy()` + `Shapes.Paste()`。
- 词组不断行：短语内部空格换成不换行空格 ` `。

### 5.5 动画（最容易出事的部分）
- 添加：`seq.AddEffect(shape, effectId, 0, trigger, -1)`，然后 `MoveTo(index)` 放到正确位置，**再显式设** `Timing.TriggerType`（参数里的 trigger 有时不生效）。
- 常用常量：Appear 1、Fade 10、Zoom 23、FadedZoom 48、Spin（强调）、触发 OnPageClick 1 / WithPrevious 2 / AfterPrevious 3 / OnShapeClick 4。
- “跟某元素一起出现”：在其效果后插入 WithPrevious（遮罩、图标、夹子、麻绳都这样同步）。
- “上一动画结束后隔 1 秒自动出现”：组内第一个效果 AfterPrevious + 延迟 1.0，同组其它效果 WithPrevious 且**各自设相同延迟**（延迟相对组开始计算）。
- 触发器（点哪个揭晓哪个）：
```python
isq = slide.TimeLine.InteractiveSequences.Add()
e = isq.AddTriggerEffect(mask, 48, 4, mask); e.Exit = -1          # 点“?”卡：卡片缩小消失
e2 = isq.AddEffect(answer, 48, 0, 2); e2.Timing.TriggerType = 2   # 答案同时放大出现
```
  COM 读回的 TriggerType 在交互序列里一律显示 4，要看 XML 的 `nodeType`（clickEffect/withEffect/afterEffect）确认。
- 页面一进入就自动播放：第一个效果设为 WithPrevious。
- **PowerPoint 读原稿时可能悄悄丢动画**（本次第 18 页丢了放大卡片的退出动画）。所以动画核对必须在 **XML 层**做（`scripts/xmlanim.py`），不能拿 COM 读出来的结果互相比。

### 5.6 遮挡与覆盖检查
- 诊断法：把某页的遮罩/对话框临时隐藏后导出，与正常导出并排比较，看清课本图原气泡的真实范围（`scripts/diag.py`）。
- 修法：遮罩/后出现的对话框做得比原气泡大一圈；同位置轮换出现的两句文字，后一个加白底；放大卡片要盖住整张图，并 `ZOrder(0)` 置顶（否则下划线等会压在卡片上）。

### 5.7 QA 脚本（`scripts/qa.py`）
最小字号、Latin 字体是否都是 Comic、文字溢出（扣除 BoundWidth 偏差）、元素是否越出安全区。外加：文字字符计数比对、`xmlanim.py` 动画比对、渲染拼图（`export.ps1` + `grid.py`）。

## 6. 踩过的坑（务必记住）

1. **WPS 会劫持 PowerPoint 自动化**：WPS 开着时，`PowerPoint.Application` 由 WPS 冒名响应（Name 显示 “Microsoft PowerPoint”，`app.Path` 却是 WPS 目录），生成结果背景缺失、曲线跑到 (0,0)、主题访问报错，而且**不报错**。
   - 每个脚本连接后先检查 `"Microsoft Office" in app.Path`，不是就中止。
   - 让用户先关闭 WPS；再结束由 COM 拉起的 WPS 自动化实例（命令行带 `-Embedding`），不要碰用户自己的 WPS 窗口。
   - 直接启动 POWERPNT.EXE 也没用，运行对象表里拿到的仍是 WPS。
2. **不要在脚本开头“关闭所有已打开的演示文稿”**，会关掉用户自己的文件（不保存）。只关闭本脚本打开的那个路径。
3. 构建结果异常时**先怀疑环境**：同一脚本先前正常、这次全乱 → 先查是谁在响应 COM，再查代码。加“金丝雀检查”（如主题字体能否访问）自动中止。
4. Bash heredoc 里写中文进 Python 可能被转码损坏 → 含中文的补丁写成文件再执行。
5. 形状名称会被 PowerPoint 按界面语言本地化（“直接连接符 1”→“Straight Connector 1”），定位一律用 id。
6. 表情符号（✅❌🌟💰）在部分设备/查看器显示不出 → 用画的 PNG 图标。
7. 弯引号 “ ” 在英文文字框里如果东亚字体槽是中文字体，会显示成全角、间距怪 → 东亚槽也设 Comic。
8. 把文字放进某个框之前确认：后加的白底文字框不能盖住下面形状的边框（第 22 页出现过“白块”）。
9. 交付前确认目标文件没被用户在 WPS/PowerPoint 里打开（会锁文件或覆盖冲突）；用户改了文件名就沿用新名字，先用 md5 确认内容没被改过再覆盖。

## 7. 和客户/用户协作的经验

- 每轮先复述理解（尤其是截图圈注、语音转写），有冲突就点明。
- 改动尽量最小化、可回退：每轮保留上一版文件和脚本备份（这次用户要求“最后一页恢复”，直接换回上一版、逐字节一致）。
- 交付说明写清：改了哪些页、为什么、哪些课本图被移动、哪些地方没实际放映测试。
- 不要假装验证过：放映点击效果、WPS/手机端显示没测就说没测。

## 8. 文件清单

| 文件 | 作用 |
|---|---|
| `scripts/example_build_unit4.py` | 本次完整构建脚本（按页的全部改法，可作范例；id 是这份课件专有的） |

| `scripts/xmlanim.py` | 两个 pptx 的 XML 级动画逐页比对 |
| `scripts/anim.py` | 用 COM 列出母版/版式/每页动画（快速查看用；注意它没有 WPS 检测） |
| `scripts/diag.py` | 隐藏遮罩前后对比导出，诊断覆盖问题 |
| `scripts/export.ps1` | 用 PowerPoint 把指定页导出 PNG（含 WPS 检测） |
| `scripts/grid.py` | 把导出的页拼成对照图 |
| `scripts/tw.py` | 用 Comic 字体文件估算文字宽度 |
| `assets/` | 背景面板、Tips 灯泡、雨伞、星/勾/叉图标、光芒图 |

用法示例：
```bash
python example_build_unit4.py src/original.pptx out/v.pptx assets/bg_panel.png
python -I post.py out/v.pptx out/vp.pptx
python qa.py out/vp.pptx
python -I xmlanim.py src/original.pptx out/vp.pptx
powershell -File export.ps1 -pptx <绝对路径> -outdir <目录> -width 1280 -slides "5,6"
```
