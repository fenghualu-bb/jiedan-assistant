# 美化 / 修改现有 PPT（在《通用.md》基础上追加）

- 【关键】允许重排每页的图文位置吗？（经验：第一轮就要问；约束太保守会导致"花钱没看到变化"）
- 【关键】改动幅度：微调统一 / 明显美化（结构页、卡片化、版式重做）/ 整体换风格
- 【关键】原有动画、触发器、音视频要不要保留（默认全部保留，用 COM 原地改）
- 统一的含义：字号统一到一个正文字号？（经验：正文 20 号、行距 1.3，不压行距）
- 需要加的结构页：目录、章节过渡页、小结页？
- 原稿里的错别字、标点、逻辑问题：直接改 / 列出来让客户定
- 学科专用图线、颜色（如工程图中心线红色）是否有教学含义，不能动
- 批注页：客户的红字/红圈批注全部列成条目，逐条对应
- 多份文件要不要跨文件统一（同一套模板、字号、页眉）
- 原稿里的 Word 公式、OLE 对象、超链接怎么处理（经验：链接文字可能要删）
- 客户说"你有你的审美，你来做"时：接下设计权，但先用一句话对齐一个最关键的点（例："不要这个绿色的边框是嘛？"），再出样张
- 客户嫌"变化不明显"时：先确认是不是要"重新设计整个视觉风格"，并提醒之前的约束（如"不花哨"）
