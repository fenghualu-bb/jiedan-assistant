# 仿理想图 / 参考图制作（在《通用.md》基础上追加）

- 【关键】仿到什么程度：照着做到几乎一样 / 只学风格配色 / 只学版式
- 【关键】参考图里哪些元素必须有、哪些不要（逐个列出图中元素让客户勾）
- 【关键】要可编辑吗：文字必须能改？框线、箭头要能改颜色吗？（手绘/彩铅质感常用 PNG，代价是不能一键改色）
- 参考图是单页还是要扩展成整套：其他页按什么规则延展
- 参考图上的文字是占位还是要照抄；新内容从哪来
- 图里的小图标、插画、装饰（经验：客户常要求删小图、同一层级同一颜色）
- 字体：参考图里的特殊字体（手写体、艺术字）电脑上可能没有，用替代字还是转图片
- 有版权的图片/角色：只学风格，不照搬素材，必要时向客户说明
