# 接单助理

代做 PPT / PDF 的接单助手。把客户的文件和聊天截图交给 AI，AI 读懂需求；没懂的，用你的口吻写追问让你转发；理解透了才开工，做完再复盘，越用越像你、越做越熟练。

## 怎么用

**Claude Code / Codex 等编程 AI**：在本文件夹里打开，直接说话即可（AI 会自动读 `AGENTS.md`）。

```
新单 王老师_说课课件        ← 然后把客户文件、聊天截图发过来
客户回复了：……              ← 贴文字或截图
开工
客户说要改：……
这单结束了
这句不像我，我会说：……
```

**网页版 AI（ChatGPT、Grok、豆包等）**：运行下面的命令，把生成的 `dist/接单助理_完整说明.md` 上传给它（只做需求沟通可用 `--lite` 精简版）。

```bash
python3 tools/pack.py
```

## 目录

| 位置 | 内容 |
|---|---|
| `AGENTS.md` | 总规则与流程（所有 AI 的入口） |
| `skills/` | 五个技能：intake 审阅、ask 追问、build 制作、revise 改稿、retro 复盘 |
| `清单/` | 各类单子必须问清的事 |
| `模板/` | 理解卡、问答记录、交付说明、案例 |
| `db/经验/playbook.md` | PPT 制作经验总结 |
| `db/口吻/` | 你的说话方式（画像 + 范例） |
| `db/案例/` | 每单复盘 |
| `订单/` | 每单工作区（不进版本库） |

## 第一次使用前

1. ✅ 口吻初版已建（7 张截图）。样本越多越像：继续往 `db/口吻/原始/` 放截图，对 AI 说"学习口吻"。
2. ✅ 经验附录、英语课件脚本、固废批量工具、两份交接文档已在 `db/经验/`（演讲稿项目的构建脚本没有拷过来）。
3. 如果要用 Git 同步，只能用**私有**仓库；`订单/` 和 `db/口吻/原始/` 已在 `.gitignore` 里排除。
