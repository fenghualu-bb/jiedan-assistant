# 通用需求清单（每单必查）

标【关键】的项目必须 ✅ 才能开工。其他项可以用"默认值"，但要在方案摘要里写明"按默认处理"。

## A. 交付物
- 【关键】交付格式：.pptx / .pdf / 两者都要 / 视频？
- 【关键】客户用什么软件打开、演示：WPS / PowerPoint / 版本？（默认按 WPS 考虑兼容）
- 【关键】截止时间（日期 + 几点）；是否分批交付
- 页数：固定 / 可增减 / 上限？
- 页面比例：16:9 / 4:3 / 保持原样？（默认 16:9；4:3 转 16:9 必须真正重排）
- 文件体积限制（比如要发微信、上传平台）

## B. 用途与受众
- 【关键】用途：上课 / 说课比赛 / 公开课 / 答辩 / 汇报 / 演讲 / 打印
- 受众与场合：学生年级、评委、领导；大屏投影还是电脑屏幕
- 演讲者是否需要备注（讲稿进备注）
- 有没有评分标准或比赛要求（要原文）

## C. 内容边界
- 【关键】内容能不能改：只美化 / 可精简文字 / 可重写 / 可补充
- 图片、视频、音频能不能换、能不能挪位置、能不能删
- 首页、尾页、目录页有没有特殊要求
- 校徽、学校名、姓名、单位要不要（经验：客户多次要求删掉）
- 有没有必须保留的元素（学科语义色、指定图片、Logo）

## D. 风格
- 【关键】风格依据：参考图 / 参考 PPT / 文字描述 / 交给我们定
- 颜色：主色、禁忌色；学校/单位规定配色
- 字体字号：最小字号要求、是否允许特殊字体（他人电脑可能没装）
- 动画：要不要 / 程度（见 `动态PPT.md`）
- "简洁"还是"丰富"：客户说"高级""大气""好看"时，要用参考图或样张落实成具体样子

## E. 验收
- 客户怎么判断满意：最在意哪 1～2 点？
- 修改轮次（【请主理人决定】，不要自己承诺）
- 是否需要前后对比图（美化单默认附上）

## F. 矛盾与歧义（每轮都要查）
- 前后说法冲突 → 以最新为准，但必须点出来让主理人确认
- 页码对不上（客户说第 26 页其实是第 25 页）→ 写出你的理解
- 截图圈了一处 → 默认"这一类全部改"，在理解卡里写明
